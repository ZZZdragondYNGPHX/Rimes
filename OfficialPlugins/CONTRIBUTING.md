# 贡献指引

感谢参与 RIMES 官方免费插件。

- 请在对应插件的说明中记录用途、支持平台、安装方法和维护者公开署名及主页。
- 提交自己有权提供的代码。除另有明确说明并经维护者接受外，有意提交并纳入本项目的贡献按 Apache-2.0 第 5 条处理，不转移贡献者版权。
- 引入既有代码或资源时保留原有版权、许可证和来源，并补充 [第三方声明](THIRD_PARTY_NOTICES.md)。
- 修改既有插件时说明改动；仅适配接口的独立插件应如实说明兼容关系，不宣称修改了未使用的上游源码。
- 提交前运行 `python3 scripts/check_repository.py`，并执行相关插件自己的构建和验证步骤。

插件目录组织、维护流程和平台构建将在实际插件接入时逐步完善。

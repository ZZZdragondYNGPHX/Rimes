# RIMES brand assets

`rimes-rhino.png` is the shared transparent master. Existing Linux hicolor
PNG icons are committed under `platforms/linux/ime/data/icons/hicolor` and
installed as `rimes`. Android/Windows retain their committed platform assets.
Apple icon exporters and bundles have been removed; Linux builds need no
Apple toolchain. Artwork provenance remains in `rhino-provenance.md`.
